**Project Overview**

MovieHub is a responsive and interactive web-based movie listing and rating platform developed using HTML5, CSS3, Bootstrap 5, JavaScript, and JSON. The project allows users to browse movies across multiple categories, search for specific films, and rate movies using an interactive star system.

The system focuses on creating a modern Netflix-style interface with smooth animations, real-time search functionality, and a professional dark-themed design for an optimal movie browsing experience.

---

**Technologies Used**

* **HTML5** – Structure of the web pages and movie cards
* **CSS3** – Styling, animations, hover effects, and responsive design
* **Bootstrap 5** – Responsive grid system and UI components
* **JavaScript** – Dynamic content loading, search functionality, and rating system
* **JSON** – Movie database storage and retrieval
* **Git & GitHub** – Version control and project hosting

---

**Key Features Implemented**

* Responsive movie listing layout with Bootstrap grid system
* Netflix-style dark themed UI with smooth hover animations
* Multi-category navigation (Bollywood, Hollywood, International, Cartoon)
* Real-time search functionality with case-insensitive filtering
* Interactive 5-star rating system with visual feedback
* Dynamic movie card generation from JSON database
* Poster image zoom effects on card hover
* Category-specific glowing text effects
* Professional card scaling and shadow animations
* Mobile-responsive design across all devices
* Automatic page detection for category filtering
* "No results found" message for empty search results
