PROJECT OVERVIEW:
================================================================================
MovieHub is a Movie Rating Website built as an Internship Task. It's a modern, 
interactive web application that allows users to browse, search, and rate movies 
across multiple genres including Bollywood, Hollywood, International, and Cartoon 
films. The project features a sleek dark-themed interface with Netflix-style 
hover effects and responsive design.

HOW IT WORKS:
================================================================================

WORKFLOW ON INDEX.html:
1. Page loads and script.js is executed
2. movies.json is fetched and parsed
3. displayMovies() is called with all movies
4. Movie cards are dynamically generated with:
   - Movie poster image
   - Title
   - Genre and Year
   - 5-star rating interface
5. Search event listener listens for keypresses in search bar
6. When user types, filtered movies are displayed in real-time

WORKFLOW ON CATEGORY PAGES (bollywood.html, etc.):
1. Page loads and script.js is executed
2. movies.json is fetched
3. Page URL is checked using window.location.pathname
4. If "bollywood.html" is detected, movies are filtered by category
5. Filtered movies are displayed using displayMovies()
6. Same search and rating functionality available

RATING INTERACTION:
1. User clicks on any star in the 5-star rating
2. rate() function is triggered
3. All stars are reset to gray color
4. Stars up to and including clicked star turn gold
5. Visual feedback confirms the rating

INSTRUCTIONS FOR FUTURE ENHANCEMENTS:
================================================================================

To add more movies:
1. Open movies.json
2. Add new movie object following the existing format:
   {
     "title": "Movie Name",
     "genre": "Genre1 / Genre2",
     "year": 2023,
     "category": "Bollywood",
     "image": "images/imagename.jpg"
   }
3. Add corresponding movie poster to images/ folder
4. Save and refresh the page

To create new categories:
1. Create new HTML file (e.g., action.html) copying structure from category pages
2. Update category button navigation on index.html
3. Add movies to movies.json with new category name
4. Script will automatically detect and filter movies

To modify styling:
1. Edit style.css with new CSS rules
2. All pages will update automatically due to shared stylesheet
3. Keep responsive design in mind when making changes
